## Features ⚡

This template is packed with a lot of features including:

- [x] Dark and light modes.
- [x] Messages with attachments.
- [x] Replies and pins.
- [x] Conversations and archives.
- [x] Settings.
- [x] Notifications.
- [x] Voice calls.
- [x] Sign in and sign up pages.
- [x] Password reset page.
- [x] and much more.

## Setup 🔧

Here is how to setup this template:

<p>1. Clone the repository.</p>

```bash
git clone https://github.com/OussamaKader/Messaging-main.git
```

<p>2. Install dependencies.</p>

```bash
npm install
```

<p>3. Run the development server.</p>

```bash
npm run dev
```
